# Газетка 2.0 — інтерактивна схема плат

Статична сторінка (без збирання) для GitHub Pages: плати, роз'єми, датчики, частотники та їх розташування на сортувальнику «Газетка 2.0».

## Види
- **Розташування** — спрощений план магістралі та трьох робочих місць (не в масштабі).
- **Бокси й плати** — бокові вигляди сортувальника з боксами, креслення боксів (Box A–D, РМ_1–3) з документа з клікабельними платами й частотниками, поруч — рендери плат NVG030_V1 і W5500 з клікабельними роз'ємами.
- **Шафа** — монтажна панель за фото: автомати QF/SF з таблицею «що живить», двері з кнопками та лампами.
- **RS-485** — порядок підключення шини.

Наведення або клік на будь-якому елементі підсвічує пов'язане на всіх видах. Справа показуються деталі: що підключено, піни, провід, джампер і де стоїть.

Стан зберігається в адресі, тож посиланням можна поділитися: `#v=plan,boards&s=c:CROSSING%202:IN_3`.

## Файли
- `index.html` — розмітка сторінки.
- `css/style.css` — стилі.
- `js/data.js` — **усі дані**: типи пристроїв, місця, координати, пристрої, плати та роз'єми, шина. Редагуйте тут.
- `js/app.js` — відображення та логіка.
- `img/` — рендери плат і креслення боксів, витягнуті з PDF (координати гарячих зон — у `BOX_IMG`, `NVG_IMG`, `W5500_IMG` у `js/data.js`).

## Публікація
Покладіть вміст теки в репозиторій (у корінь або в теку `docs/`) та увімкніть GitHub Pages для цієї гілки й теки. Файл `.nojekyll` вже є.

## Поза схемою (поки)
Верхні поверхи (2–6) і ліфти. Їхні плати й автомати показані сірим / «поза схемою» лише для розташування.
